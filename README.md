2. 🍅 Explainable Web-Based Tomato Disease Detection Using Lightweight CNN

Project Type: MSc Project / Machine Learning / Computer Vision
Focus: Image Classification, Lightweight CNN, Explainable AI & Web Application

Overview

This MSc project focuses on developing an explainable web-based tomato disease detection system using a lightweight Convolutional Neural Network (CNN).

The system is designed to classify tomato leaf images and identify potential diseases while providing an interpretable explanation of the model's prediction.

The project combines deep learning, computer vision, explainable AI (XAI), and web application development to create a practical and accessible disease-detection solution.

Key Objectives

Develop a lightweight CNN for tomato leaf disease classification

Preprocess and prepare tomato leaf image data

Train and evaluate the deep-learning model

Reduce model complexity while maintaining useful classification performance

Integrate the trained model into a web-based application

Provide visual explanations for model predictions

Improve transparency and user understanding of AI-based diagnosis

Explainable AI

The project incorporates explainability techniques to help users understand which regions of an input tomato leaf image contributed to the model's prediction.

This is particularly important for agricultural AI applications, where users may need greater transparency and confidence when interpreting automated predictions.

Web Application
